# claudeFF

面向 Windows 的独立浏览器环境与代理管理工具。当前先实施前端设计与网页预览，用户认可设计风格后再开发后端。

网页预览：**https://yingziseo.github.io/claudeFF/**。直接点击「进入工作空间」即可体验；登录不验证账号，全部业务数据为示例。

所有构建及需要编译的验证使用 GitHub Actions。先完成浏览器核心与中文界面并测试，最后加入联网卡密和用户管理面板；最终提供可运行的 Windows 免安装 ZIP。

前端位于 `frontend/`。网页预览中的环境、IP 和运行状态是明确标记的示例，不执行真实代理检测或浏览器操作。不要在当前服务器执行 npm 安装、构建、测试或预览服务；使用仓库的 `Frontend preview` 云端工作流。
