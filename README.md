# claudeFF

Windows 11 x64 个人 Claude 工作空间：**一个账号、一份稳定环境配置、一份全局代理**。Claude.ai 使用独立指纹 Chromium，Claude Code 使用专用 WSL2 整进程隔离；Claude 桌面客户端保留“正在开发中”入口。

新版界面、Windows 核心及后期授权服务已实现，已发布 v0.2.0-dev.1 开发体验版。Windows/WSL2 真实安装、用户代理及官方账号体验由用户实机验证；生产授权服务未部署，当前 ZIP 保留开发登录。

- [客户端界面预览](https://yingziseo.github.io/claudeFF/)：新版单账号界面，连接、安装和终端为明确标记的示例。
- [卡密和用户管理面板预览](https://yingziseo.github.io/claudeFF/#admin)：示例管理界面。
- [Windows ZIP 与授权服务开发产物](https://github.com/yingziseo/claudeFF/releases/tag/v0.2.0-dev.1)：解压运行说明随包提供。
- [开发进度与验证报告](docs/开发进度与验证报告.md)：具体通过证据与实机待测项。

## 当前功能

| 模块 | 实现 |
| --- | --- |
| 全局连接 | HTTP/HTTPS/SOCKS5、认证、受管回环转发、真实出口检测、失败禁止直连、DPAPI 保护密码 |
| Claude.ai | 固定版本开源指纹 Chromium 下载与摘要校验、稳定种子、独立持久 profile、真实浏览器出口复核、环境信息与官网默认标签页 |
| Claude Code | 专用 WSL2 导入、官方安装、语言/时区沿用、整进程目录限制及 UID 出站限制、PTY 终端、项目副本导入 |
| 界面 | 官方 Claude 素材、Lucide、简体中文、深浅主题、高级指纹、键盘与窄屏、加载/失败恢复 |
| 后期授权 | 永久卡密、产品账号、激活/心跳/撤销、用户在线与使用状态、真实管理面板；生产策略和部署待完成 |

## 开始体验

下载并解压完整 Windows ZIP，保留 `sandbox/` 与程序的相对位置。填写全局代理并检测，再打开浏览器或准备 Code。浏览器内核按需下载；Code 需要 WSL2、虚拟化及首次系统准备。详细步骤见 [Windows 运行说明](docs/Windows运行说明.md)。

授权服务是独立 Linux 程序加轻量网页面板，见 [授权服务运行说明](docs/授权服务运行说明.md)。公开网页预览与真实服务分开；开发 ZIP 尚不要求卡密。所有依赖安装、构建、类型检查和测试都在 GitHub Actions，本机没有执行项目构建。
