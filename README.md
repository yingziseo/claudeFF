# claudeFF

面向 Windows 11 x64 的个人 Claude 工作空间：**一个账号、一份稳定环境配置、一份全局代理**。首期实现 Claude.ai 指纹浏览器与 WSL2 强隔离 Claude Code；Claude 桌面客户端只预留“正在开发中”入口。

当前正在按新需求重整文档和重做前端。先提供网页预览，用户认可风格后才进入后端；浏览器和 Code 核心都通过测试后，最后加入联网卡密与卡密和用户管理面板。

## 当前状态

- [现有网页预览](https://yingziseo.github.io/claudeFF/) 仍是被否定的旧多环境设计，**不是 V2 新版**。
- 新需求文档已统一；新版 UI、全局代理、真实浏览器与 WSL2 Code 尚未实现。
- 旧预览有明确示例数据，登录不验证账号，不执行真实代理/浏览器/安装操作；旧测试结果不能用于证明新需求完成。
