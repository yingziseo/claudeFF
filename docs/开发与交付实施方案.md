# 开发与交付实施方案

版本：V2 · 2026-10-10。用户已取消前端优先和风格确认门槛，授权按技术依赖自主完成整体开发，最后测试优化界面。本文件取代原“前端优先实施方案”。

## 已执行顺序

1. 同步单账号、三入口、全局代理、WSL2 强隔离和后期授权需求。
2. 建立 Go 持久化/代理/秘密模块与新版前端，明确网页示例与真实桌面绑定边界。
3. 接入真实指纹 Chromium、专用 WSL2、整进程目录/出站限制、官方 Code 安装、PTY 与项目副本。
4. 核心首轮模块和隔离云测、Windows 编译通过后，加入授权服务及卡密和用户面板。
5. 集中做前端交互、布局、键盘、失败恢复与真实管理面板测试；补真实 Windows 内核及官方 Code Linux 安装证据。
6. GitHub 云构建开发 ZIP 与服务包，汇总进度及用户 Windows 实机清单。

## 交付范围

- Windows 11 x64 ZIP：Wails 程序、静态 Linux helper、隔离脚本、运行说明、来源与 SHA256 文件。
- 网页预览：单配置三入口、全局连接、指纹详情、Code 复用/单独路径、开发登录、深浅主题与窄屏。网络、安装及终端始终标记示例。
- 授权服务包：Linux x64 单程序、真实 API 管理面板及部署说明；公开 `#admin` 为分开的示例。
- 文档：需求、当前技术、UI 规范、来源、运行说明、验证报告和工作日志一致。

预览不执行安装、不上传代理秘密、不 iframe 官方登录页，不以模拟状态证明业务通过。正式桌面操作通过 Go/受管进程真实执行。

## 后续验收

用户已明确稍后自行在 Windows 安装体验，当前环境无需为了模拟 Windows 在低配服务器运行构建。实机清单见 [Windows 运行说明](Windows运行说明.md)。核心已实现但实机未测项保持未验证。

商业发布还需要正式授权策略、HTTPS 域名/服务配置、备份与访问控制、完整发行通知，以及关闭开发入口的正式 Windows 产物验收。Claude 桌面集成按约定仍不在本期。

每个重大更新记录并正常 push；全部构建与测试留在 GitHub Actions。已通过检查不因文档补记而无意义重复，改变代码/包装时验证对应新提交。
