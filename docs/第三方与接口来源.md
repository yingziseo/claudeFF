# 第三方与接口来源

本包包含本项目编译的应用和 .NET 自包含运行时。保留包内 .NET 的 LICENSE/ThirdPartyNotices 等原始文件。Sandboxie 不随包分发，用户另行安装原版。

- Sandboxie 的组件许可证各不相同：https://github.com/sandboxie-plus/Sandboxie/blob/master/LICENSE.Plus 。部分功能需要适用证书。开源核心并不等于所有界面或商业使用均无条件开放。
- 官方 SbieDll API：https://sandboxie-plus.github.io/sandboxie-docs/Content/SBIEDLLAPI/
- 配置查询实现：https://github.com/sandboxie-plus/Sandboxie/blob/master/Sandboxie/apps/ini/query.c
- 命令行启动：https://sandboxie-plus.github.io/sandboxie-docs/Content/StartCommandLine/
- 文件访问限制：https://sandboxie-plus.github.io/sandboxie-docs/Content/ClosedFilePath/
- 注册表访问限制：https://sandboxie-plus.github.io/sandboxie-docs/Content/ClosedKeyPath/
- SOCKS5 重定向及覆盖边界：https://sandboxie-plus.github.io/sandboxie-docs/PlusContent/ProxySupport/
- 官方模型改进设置：https://privacy.claude.com/en/articles/12109829-how-do-i-change-my-model-improvement-privacy-settings
- 官方位置设置边界：https://privacy.claude.com/en/articles/11186740-does-claude-use-my-location
- ipify：https://www.ipify.org/ 。仅用户点击检测或启用代理验证时向其查询出口 IP。
- 可选外部页面：https://scamalytics.com/ip 、https://browserleaks.com/dns 。不抓取或计算“纯净度”评分。
- .NET：https://github.com/dotnet/runtime ，WPF：https://github.com/dotnet/wpf 。

没有使用 Claude Code 的遥测环境变量冒充 Claude Desktop 设置。未打包 ProxiFyre；实验性 TCP 模式使用 Sandboxie 官方重定向能力及本项目的窄范围 SOCKS 桥接。

应用图标按项目设计约定使用 Claude 官方 favicon，来源：https://claude.ai/favicon.ico ，获取日期 2026-10-12。本工具为第三方工具，与 Anthropic 无隶属关系。图标不是本项目原创素材。
