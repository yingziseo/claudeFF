# 代理与内置资源修复方案

**2026-10-12 修订：** 再次收到代理检测异常和秒退出反馈。本轮以完整产品二次开发为方向，免费 IP 接口验证代理链路、地区查询为补充，检测站异常与代理认证/连接失败分开。禁止因外部探针失败自动关闭正常浏览器，禁止公网直连回退。以下是 V3 实现/证据，不代表本轮完成，见 [基座评估](指纹浏览器基座选型评估.md)。

2026-10-11 · V3。用户真实反馈：代理检测只显示笼统失败，且内核要求首次下载，导致无法使用。当前改为完整资源交付和真实原生验证。

轻量独立诊断已验证用户授权网关：HTTP 与 SOCKS5 都能返回匹配出口，地区 Singapore/SG，时区 Asia/Singapore，请求耗时约 332–781ms；这是诊断证据，不替代 Windows 客户端链路。凭据只用于临时加密云测，不进入文件、日志、图片或发布包。直接请求 Claude.ai 曾得到 403，不据此宣称官网登录成功。

修复内容：四段式/URL 导入、阻止完整认证串误存为主机、保留 407 与连接/协议/超时原因；ipify/api64/ipinfo 备用站始终走同一代理，地理信息查询必须匹配已检测 IP。代理只测响应，不推断住宅属性或“安全分”。

ZIP 内置完整原生 fingerprint-chromium 和固定 WebView2，直接查找随包目录。取消内核下载按钮及自动下载。微软运行时记录固定来源/版本/摘要并核验执行文件签名。macOS 使用系统 WebView，内核须核验架构。不含已取消的 WSL/Linux 资源。

浏览器出口采用独立临时标签验证，原生会话加 URL 检查点恢复之前对话；保留 profile。Code 正常官方原生安装，注入共享代理，不同步指纹或引入隔离环境。

界面加入一键粘贴、保存并检测、真实地区/耗时、可恢复失败。IPDeep 本地原图与用户推荐链接均可点开，红字固定为：中国大陆网络，无法直接使用代理服务，请您自行准备海外网络环境。

验收需实际 Windows Wails/WebView2 窗口读取系统剪贴板、经过 Go 绑定保存真实代理、返回地区与延迟、启动随包内核并复核出口；官方 Code 则通过受控认证测试代理真实安装/启动，避免借用户代理下载大二进制。前端 mock 不算真实链路通过。

依据：[Wails 固定 WebView2](https://wails.io/docs/guides/windows/)、[微软运行时分发](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)、[Code 网络配置](https://code.claude.com/docs/en/network-config)。具体成功/失败状态统一记录到验证报告。
