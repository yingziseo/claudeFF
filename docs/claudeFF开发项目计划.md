# claudeFF 开发项目计划：单账号 Claude 工作空间

版本：V3 · 2026-10-11。本文为当前需求基线，替代旧多环境方案和 V2 的 Code 强隔离方案。用户最新明确要求优先；历史工作日志仅供追溯。

## 产品范围

一个用户、一个 Claude 账号、一份全局代理、一份持久浏览器配置。Windows 11 x64 是主要交付平台，新增 macOS 原生 Claude Code 支持；各平台产物和验证分别说明。

| 入口 | 当前要求 |
| --- | --- |
| Claude.ai | 完整开源 fingerprint-chromium 内核，原生标签、地址栏、密码、历史、书签、下载与独立用户目录 |
| Claude Code | 在 Windows/macOS 正常安装官方原生版本，自动使用同一份全局代理，提供真实交互终端和本机项目选择 |
| Claude 桌面版 | 预留入口，显示“正在开发中” |

Code 不需要先创建浏览器环境或登录网页。取消 WSL2、虚拟机、bubblewrap、防火墙、独立项目副本、时区/语言同步和指纹差异确认弹窗。不得继续实现或宣传这些已取消的要求。Code 为官方非完整开源程序，不修改其源码。

## 全局连接

只保存一份 HTTP/HTTPS/SOCKS5 上游；Code 原生 HTTP/HTTPS 代理通过应用回环转发适配 SOCKS5。启动进程注入 `HTTP_PROXY`、`HTTPS_PROXY`，消除冲突大小写变量和外部 NO_PROXY；不修改系统代理，不覆盖用户 Claude settings.json。正常官方登录独立进行。

支持一键读取剪贴板及识别框粘贴，识别主机:端口:用户名:密码、代理 URL、认证格式；密码遮蔽并受系统秘密存储保护。保存并检测为主操作，失败分类显示格式、认证、连接/超时、协议和检测站错误。备用检测站始终使用同一代理，不自动直连。

显示实际出口、国家/城市、时区、检测站、响应耗时和时间；住宅属性缺乏证据显示“未验证”。地区结果来自网络查询，浏览器配置时区另行展示。改代理前停止本应用运行的浏览器/Code，旧检测同时失效。

原生 Code 可以知道自己设置了代理，也可能读取本机信息；本方案不限制其所有子进程出站，不承诺隐藏真实 IP 或无法识别代理。该边界写在技术文档，不在主流程堆砌提示。

代理页加入 IPDeep 商家原图与推荐链接，图片和按钮均打开 https://www.ipdeep.cn/?extendid=30d6N2VjYjI3MzQ4NDUyNTY3OTQxMTg5 。显示多地区选择、用户指定特价区最低 $2/IP 文案。固定红字：**中国大陆网络，无法直接使用代理服务，请您自行准备海外网络环境。** 素材本地随包。

## 真实指纹浏览器

复用 [fingerprint-chromium](https://github.com/adryfish/fingerprint-chromium) 成品 `148.0.7778.215`，保留全部原生 Chromium 文件，不自行编译 Chromium。Wails 的管理 WebView 不替代浏览器。

首次启动开环境信息页与 https://claude.ai/。以后恢复上次打开的标签和具体对话 URL，保持原生导航记录、Cookie、密码、历史、书签。稳定指纹种子与专用 browser-profile 目录长期保留，更新 ZIP 不覆盖数据。启动检测使用单独临时标签，不覆盖恢复的对话；环境信息页重启后更新本地地址，不重复堆积官网标签。运行期间保存私有 URL 检查点，异常退出尽可能恢复；不保存网页内容到管理数据库。

浏览器内实际核验出口，不能把 Go 探针成功当浏览器已验证。高级设置显示 UA/UA-CH、平台、语言、时区、Canvas、Audio、WebGL、屏幕、CPU/内存及能力状态。未知/未测试如实显示，不冒充 CLI 指纹，不宣称绝对防封。修改浏览器配置前停止浏览器。

## 原生 Claude Code

流程：检查全局连接 → 通过代理获取官方版本/清单/二进制 → SHA-256 校验 → 调用官方 `claude install stable` → 验证实际版本 → 启动本机终端。Windows 使用 ConPTY，macOS 使用 PTY。不依赖 WSL、Linux 镜像、额外沙箱、Node.js 或 npm。用户已有官方安装可识别复用；官方自动更新仍按其行为运行。

本机项目目录直接作为工作目录，不复制、不自动导入虚拟系统。支持输入输出、Ctrl+C、尺寸变化、停止、退出与再次启动。安装和启动失败有真实原因/重试/取消，不能伪造进度。Code 官方授权不复制浏览器 Cookie。

## UI 与存储

简体中文，接近苹果原生工具的简约体验，默认深色、完整浅色、键盘可用、窄屏无溢出。Claude 官方图标 + Lucide；高级指纹收起，初学者只需粘贴代理、保存检测、点击入口。开发版产品注册/登录为纯 UI，任意输入跳过，不作真实认证。

SQLite 保存唯一浏览器配置、唯一代理、检测历史；Windows DPAPI/macOS Keychain 保护代理秘密。浏览器数据、Code 官方用户数据与程序包分开，升级不删除登录或项目；清缓存不删 Cookie/密码。停止仅影响本应用启动的进程。退出有运行任务时提示。

## 打包、云构建与验收

Windows ZIP 内置完整指纹 Chromium 与固定 WebView2；macOS 包使用系统 WKWebView，内置平台兼容的指纹内核。基础资源在 GitHub Actions 获取、校验、包装，用户不再下载内核。只有 Claude Code 本体在线安装。不包含已取消的 WSL MSI/Linux 镜像/helper。

所有安装依赖、构建、类型检查、测试、截图在 GitHub Actions，当前服务器只编辑、Git 和轻量网络诊断。测试必须对应真实提交：模块测试、真实 Windows 原生 Wails 绑定和 UI、用户授权代理检测/地区/延迟、完整内核启动、恢复标签/存储、官方 Code 原生安装及 PTY；macOS 不能用 Windows/Linux 结果冒充。真实账号/模型调用由用户体验，不编造登录成功。

两项核心测试后才完成商业授权收敛。永久联网卡密与轻量“卡密和用户管理面板”管理卡密、激活用户、授权/在线状态及使用概况；不上传对话、代码、Cookie、代理秘密。开发包暂不要求卡密，生产未部署，不作为正式售卖验收。重复激活/换机/离线策略后续确认，不擅加设备绑定、套餐、支付、订单或团队。

当前实现、云测、下载链接与未验证事项统一见 [开发进度与验证报告](开发进度与验证报告.md)。重大更新写工作日志并 push，继续已授权开发直到交付可下载产物。
