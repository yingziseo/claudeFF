# claudeFF UI/UX 设计约定

状态：需求和设计规范，尚未完成页面实现及视觉验收。

## 产品定位与质量目标

这是管理独立浏览器环境、代理及一致性配置的 Windows 桌面工具。用户应能清楚判断：当前操作针对哪个环境、代理是否可用、浏览器是否真实运行，以及失败后如何处理。

设计必须现代、专业、可信且精致；信任来自一致的视觉、正确的数据与可预期的行为。UI/UX 与功能真实性同为验收要求。

## 视觉方向

- 参考 Linear、Raycast 和 Cursor 的紧凑桌面交互，保持 claudeFF 自己的品牌与术语，不照搬企业后台模板。
- 默认深色，同时完整实现浅色；主题切换即时生效并持久化，不只更改背景。
- 采用克制的石墨灰层次与柔和蓝色主操作，运行、警告、错误使用独立语义色，同时提供文字说明。
- 主色建议为背景 `#10141C`、面板 `#171C26`、边框 `#2A3242`、主文字 `#EDF1F7`、次文字 `#98A6BA`、主操作 `#6A9CFA`；最终实现时复核对比度。
- 中文正文使用 Windows 本地中文字体，英文品牌使用 Segoe UI 字体系列，IP 和版本使用等宽字体；界面字体不依赖外部字体网络请求。
- 统一紧凑间距、控件高度和圆角。图标使用同一套 Lucide SVG，避免 Emoji 充当结构图标。
- 不使用无关统计卡片、大面积装饰渐变、虚假安全认证或无依据的成功指标。

## 信息结构

```text
┌──────────────┬───────────────────────────────────┐
│ claudeFF     │ 当前页面 / 搜索 / 主要操作          │
│              ├───────────────────────────────────┤
│ 浏览器环境   │ 环境 / 代理 IP / 地区 / 状态 / 操作 │
│ 设置         │                                   │
│              │ 表格、空状态或创建流程              │
│ 账户或开发态 │                                   │
└──────────────┴───────────────────────────────────┘
```

- 导航仅保留浏览器环境和设置；账户信息或开发模式信息放侧栏底部。
- 页面有唯一明确的主操作。环境名称、代理和运行状态易于对应，关键操作不依赖悬停才能发现。
- 环境标识在表格、创建确认和 Chromium 首页一致，减少操作错环境的风险。
- 适配常见 Windows 桌面窗口和 DPI 缩放，保持窗口拖动、缩放和原生控制可用。

## 注册与登录

- 登录和注册拥有完整的品牌、表单、焦点、提交反馈和页面切换，界面质感与主客户端一致。
- 前期仅做前端交互：可预填测试内容，随意输入后点击进入；不请求账号或授权服务器，不生成虚假注册、授权记录。
- 开发版本清晰标识开发模式。正式版本再连接真实账号、卡密和会话逻辑，发布验收必须检查跳过入口已关闭。
- 表单使用可见标签，错误紧邻输入框，不只依赖占位文字或提示颜色。

## 环境管理与创建

- 使用真实环境表格，字段为环境、代理 IP、地区、状态和操作；搜索、启动、关闭、编辑和删除的状态清楚。
- 创建分两步：先填写并真实检测代理，再填写环境名称和检查自动配置；代理失败不能进入可启动环境的保存流程。
- 检测、启动和关闭显示可理解的进行中状态，阻止重复提交。失败提供具体原因与可用的重试入口。
- 重试保留用户填写内容；重新检测或改变代理时使旧检测结果失效，不能沿用过期的成功标记。
- 删除环境明确说明浏览数据的处理范围。运行中修改关键配置或删除时，引导先关闭环境。
- 首次使用的空状态说明下一步，后端加载失败显示错误和重试，不得冒充空列表。

## 设置与 Chromium 首页

- 设置仅包含计划要求的主题、内核位置、本地数据目录、检测超时、缓存清理、账号退出和版本信息；开发期无真实账号时不伪造退出登录的安全效果。
- 内核缺失、路径错误、数据不可写和未支持能力都有明确文字反馈。
- Chromium 首页与客户端使用相同视觉语言，通过该浏览器真实网络路径展示信息，资源尽量本地提供。
- IP 未成功检测时不展示历史结果冒充当前值；历史结果若保留，明确标注时间和当前未验证状态。

## 交互与可访问性验收

- 所有功能可用键盘操作，Tab 顺序合理，焦点可见；弹窗管理焦点并支持合理的 Esc 关闭。
- 加载、空状态、成功、失败、重试、禁用和危险操作确认都有设计；信息不能只靠颜色表达。
- 保持对比度、中文可读性和文本缩放；图标按钮有可理解的名称。
- 减少动画时尊重系统偏好；动效服务状态变化，不影响操作响应。
- 分别评审深色、浅色、窄窗口、高 DPI、长环境名称和网络失败下的页面。
- 实现后在云端生成视觉检查材料，并在真实 Windows 客户端验证窗口和交互；文档规范不能替代视觉验收。
