# 前端 UI/UX 设计风格要求

整理日期：2026-10-12。

本文件仅保留用户已明确的界面风格与交互偏好。旧项目代码、技术方案、开发计划、实现状态和测试结论均已清理；新项目的功能范围、技术栈与开发安排以用户后续提供的文件为准。本文件不代表旧界面已经获得认可。

## 1. 整体定位

- 接近苹果原生应用：现代、简约、精致、自然，兼顾 Windows 用户的窗口操作习惯。
- 工具应让初次使用者无需理解专业概念即可完成主要操作。复杂内容隐藏在高级设置中。
- 信任感来自清晰布局、统一细节、真实反馈与稳定交互，不依赖营销文案或装饰。
- 界面干净、克制、低噪声；优先减少步骤、无效信息与重复控件。

## 2. 视觉规范

- 默认石墨深色，提供完整浅色主题，切换即时生效，保持文字、边框、控件与状态的对比度。
- 使用系统字体，兼顾中文阅读与平台原生观感。数据与终端内容使用等宽字体。
- 页面标题建议 25–28px，正文与主要操作建议 13–15px，辅助文字不宜过小。
- 圆角以 8–13px 为起点；统一间距、控件高度、图标尺寸、边框和阴影。
- 通过留白、字号与层级组织内容。一个区域突出一个主要操作，次要操作适度弱化。
- 避免大面积渐变、厚重阴影、装饰性统计卡片、假安全徽章、仿浏览器模型和无意义动画。
- 上述尺寸是设计起点，最终应通过真实窗口和高 DPI 截图调整，不机械套用旧布局。

## 3. 图标与素材

- 若新项目继续围绕 Claude，项目标识及 Claude 产品入口按用户要求采用 Claude 官方图标，素材来源记录在本文件中。
- 常规功能图标统一使用 Lucide 等主流图标库，保持同一风格、笔画与尺寸。
- 不再使用此前自制或生成的项目 logo。用户后续明确要求新素材时，再按新要求处理。
- 品牌素材优先采用适合高 DPI 的原始矢量资源；不放大低分辨率小图。
- 官方来源参考：[Claude 官网](https://claude.com/)。此前本地图片与图标文件已随旧代码清理，这里保留的是选材要求。

## 4. 信息与文案

- 全部用户界面使用简体中文；保留产品名称和必要的技术标识。
- 文案只帮助用户理解当前状态或下一步操作。删除重复解释、宣传口号、无价值说明和实现细节。
- 按钮直接写动作，例如“打开浏览器”“保存并检测”“复制”“重试”，同一动作使用同一名称。
- 错误就地展示明确原因和可行操作；保留用户已填写内容。
- 实际观测、配置值、未知状态和演示数据应清楚区分，不展示虚构的可用状态、性能或安全承诺。
- 网页预览须明显标记“示例数据”或“界面预览”，不得让人误以为真实业务已经接通。

## 5. 交互体验

- 合理预填默认值，减少手动输入；适合导入的信息提供一键粘贴、自动识别与填充。
- 高级选项按需展开，默认主流程不要求理解网络或指纹术语。
- 密码默认遮蔽；复制、粘贴、保存等操作有简短反馈。
- 完整处理加载、空状态、成功、失败、禁用、重试和确认，忙碌时防止重复提交。
- 破坏性操作应明确说明影响范围并确认，不能静默清理用户数据。
- 弹窗支持 Escape 关闭、键盘操作、焦点约束与关闭后的焦点恢复；按钮有清晰焦点样式。
- 动画短而自然，尊重系统“减少动态效果”设置。

## 6. 原有页面的视觉参考（仅在新版保留相关页面时适用）

### 工作空间与工具入口

主要工具入口、共享连接状态和必要操作应清楚直接；不堆叠无关概览、分组、统计或重复导航。尚未提供的入口清楚标记“正在开发中”。终端区域优先留给实际输出和输入。

### 代理表单

支持“粘贴识别”，认证项渐进展开。结果突出出口 IP、地区和请求耗时；详细参数放在次级区域。错误不能只给模糊的一句“不可用”。

如新版继续保留用户指定的 IPDeep 推荐位，应使用商家原图，图片与文字链接一致，避免压过主操作：

- 推荐链接：https://www.ipdeep.cn/?extendid=30d6N2VjYjI3MzQ4NDUyNTY3OTQxMTg5
- 原图来源：https://user.ipdeep.cn/img/img600400.Cm9Pgb3x.png
- 用户给定推荐文案：“静态住宅代理 IP · 多地区选择 · 特价区最低 2 美元/IP”。价格属于此前给定文案，不代表当前已核验报价。
- 红字提示必须使用原句：**中国大陆网络，无法直接使用代理服务，请您自行准备海外网络环境。**

### 浏览器启动页与高级信息

参考用户提供的比特浏览器截图的信息层级：突出出口 IP、复制与刷新；下方有序展示地区、时区、语言、环境、内核与实际 User-Agent。避免无关多账号字段、分组、2FA、密码及营销内容。

- 用户参考文档：https://docs.qq.com/doc/DSW15aEZWakNuVEtU
- 如保留检测入口，提供 [ToDetect](https://www.todetect.cn/) 和 [BrowserLeaks](https://browserleaks.com/)。
- 高级信息明确区分配置值和实际观测值，未知项目如实显示。
- 含用户信息的参考截图不提交公开仓库；旧截图和效果图不作为新版已认可设计。

## 7. 界面验收

- 检查真实桌面窗口、深浅两套主题和高 DPI 显示效果。
- 1280×800 窗口下主要操作可见；网页预览在 375px 窄屏仍可阅读与操作。
- 检查键盘导航、焦点、表单校验、加载反馈、错误恢复与弹窗行为。
- 提供可直接访问的网页预览，方便用户评审，不要求先下载桌面 ZIP 才能看设计。
- 不把效果图、演示交互或旧项目测试结果当成新项目真实功能验收。
