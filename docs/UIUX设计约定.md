# UI/UX 设计约定

版本：V2 · 2026-10-10。新版已按本规范重做并完成云端交互/截图复核；用户审美反馈及 Windows 原生体验仍可继续修订。产品范围以 [开发项目计划](claudeFF开发项目计划.md) 为准。

## 方向与信息结构

接近苹果原生应用的简约、清晰和流畅体验，保留 Windows 窗口操作习惯。为个人 Claude 使用设计，不做多账号运营后台。默认深色，完整浅色切换；减少文字密度，正文清晰可读，高级内容渐进展开。

```text
个人工作空间
├─ Claude.ai：创建 / 打开 / 关闭浏览器、启动页预览
├─ Claude Code：安装 / 进度 / 官方授权提示 / 终端
├─ Claude 桌面客户端：正在开发中（不可启动）
├─ 全局连接：唯一代理设置、两端实际出口及检测时间
└─ 设置：外观、指纹详情、隔离状态、数据与版本
```

主页面只突出当前可执行的下一步。移除多环境表格、环境搜索、批量新建和多组代理卡片。浏览器页、Code 页都能看共用连接状态，修改动作始终跳至同一处全局代理。

## 品牌、字体与控件

- 项目与三个产品入口使用 Claude 官方图标，按 [品牌素材记录](品牌素材记录.md) 记录来源，不再使用旧 imagegen 图标。
- 常规设置、返回、文件、复制等使用 Lucide；线宽和尺寸统一，不用表情符号或手绘品牌替代。
- 明确第三方工具身份；官方素材不代表官方出品。保持简短说明，不挤占主操作。
- 本地中文系统字体，英文采用 Segoe UI 等，IP/版本/终端用等宽字体。不依赖远程字体。
- 主题使用语义令牌；文本、控件边界、警告及焦点都覆盖深浅主题。当前采用石墨深色/暖白浅色与官方橙色点缀，旧蓝色多环境表格已经移除。
- 大多数操作触控目标至少 44px，正文原则上 14–16px，辅助信息不缩成难辨识的小字。

## 全局代理与状态

一次填写协议、主机、端口、可选用户名密码。协议与认证可渐进展开，但状态不能隐藏。实际检测显示连接、出口、地区、延迟和错误。未验证住宅属性明确标记。

浏览器和 Code 的状态并列可比较：未启动、检测中、已验证及时间、失败/不一致。禁止只有一个绿色“安全”标签掩盖尚未检测的一端。修改全局代理提示将影响两端，并让旧结果失效。

## 浏览器主流程

配置全局连接 → 创建唯一稳定环境 → 打开浏览器。主按钮随状态变化，运行中再次点击激活已有窗口。不能让用户重复创建多个环境。

启动页与真实浏览器入口保持区分。启动页展示出口、地区、语言、时区、内核和环境信息，提供查看指纹详情；第二默认标签页打开 claude.ai。网页预览可演示两个页签，但不能把普通浏览器跳转描述成已经开启指纹代理浏览器。

## Code 的两条路径与进度

已有环境：点击安装，自动引用已有配置。没有环境：先显示差异提示与两个选择，不强迫用户登录网页端。

固定提示文案：

> 直接创建 Claude Code 环境，可能与该账号原有网页端的环境信息不同；若代理 IP 也不同，会增加环境差异。建议优先沿用原有浏览器环境，保持一致。

按钮：“先配置浏览器环境”“了解差异，继续设置 Code”。单独创建后再启用浏览器复用同一配置。

安装状态依次可见：准备隔离沙箱、下载安装 Code、同步配置、核验出口与隔离、启动终端。总体提示“正在下载安装，并同步浏览器环境配置，尽量保持环境和设备信息一致”；详情必须按实际完成项目显示，不把全部指纹宣称同步。

提权、重启、选择项目、官方登录等需要用户处理的步骤明确等待，不做无限转圈。失败展示原因、当前保留成果、重试/取消；不提供“跳过隔离继续”。安装成功不等于 Code 已授权。

## 高级设置

查看语言、时区、UA/UA-CH、平台、分辨率、Canvas/WebGL/Audio/字体、WebRTC、DNS/IPv6、权限及内核能力；分开呈现配置值和真实观测值。显示待验证、不支持和平台差异，禁止伪造绿色通过。

Code 显示同步适用字段、WSL 实际平台、项目访问范围、隔离核验结果与版本。Canvas 等标为浏览器专属。主页面不要求新手理解这些参数。

## 开发登录、预览和可访问性

- 开发 ZIP 与网页预览的产品登录/注册为前端交互，随意输入可进入；正式模式已接真实授权 API，强制登录和字段反馈，不能关闭必需登录弹窗。两者均与 Claude 官网登录/Code 授权分开。
- 预览醒目标注“界面预览 / 示例数据”，不保存上传用户填入的密码，不执行真实安装或网络检测。
- 操作有加载、失败、重试、禁用和危险确认；删除/清缓存说明范围并保护登录与项目数据。
- 键盘可达、可见焦点、弹窗焦点恢复和 Esc、图标可访问名称；状态同时用文字表达。
- 150–250ms 克制动效，尊重减少动画偏好；测试窄屏、文本放大、高 DPI 和深浅主题。
- 在 GitHub 云端测试并截图，按用户最新授权整体完成后集中测试优化界面；浏览器截图不替代 Windows 原生交互验收。

## 本轮优化与验收记录

已优化 1280×800 主按钮首屏可见、窄屏产品文字导航、跳转主内容、焦点/弹窗、减少动画、异步错误、初始化失败恢复和下载状态。首次桌面打开自动准备内核，失败不继续启动；Code 停止后保留安装和版本、允许重新启动。高级参数分开显示配置与实际观测，未知权限/字体/完整链路不标为通过。详见 [前端测试与优化记录](前端测试与优化记录.md)。
