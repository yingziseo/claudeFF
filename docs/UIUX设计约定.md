# UI/UX 设计约定

2026-10-11 · V3，按用户“降噪、克制、干净”的最新要求。

工具主流程只有：配置一次代理 → 打开浏览器 / 使用 Code。官方 Claude 图标配 Lucide，保持石墨深色/清洁浅色与系统字体。标题 25–28px、操作 13px、圆角 8–13px；不用大渐变、虚假安全徽章或装饰性浏览器/终端模型。

首页两个简单入口卡片和代理状态，桌面版只显示开发中。浏览器页只放启动/关闭、真实状态和指纹入口；不在管理 WebView 假装有完整浏览器。Code 页只放官方安装/启动/停止、本机项目选择及真实终端，取消沙箱步骤、指纹同步和旧差异弹窗。

代理页提供“粘贴识别”及快速导入，主操作为“保存并检测”；真实出口、国家/城市、请求耗时、时区。认证项渐进展开、密码遮蔽。失败就地给原因、保留输入，忙碌时不重复提交；运行中提示先停止。IPDeep 使用商家原图和指定链接，固定大陆网络红字保持可见。

删除重复说明、营销标题、架构术语、长安装解释与无价值信息。每个文案只说明此刻用户需要做什么。复杂参数收进“浏览器指纹”，实际/未知分别显示；Code 无伪指纹展示。

键盘焦点清晰、弹窗 Escape/焦点恢复、跳到内容、减少动画；375px 窄屏和 1280×800 主按钮可见。网页预览始终标记“示例数据”，不当真实业务验收。开发产品登录任意输入，官方登录独立。

依照 frontend-design 的克制原则，截图/交互测试均在 GitHub Actions；结果见 [前端测试记录](前端测试与优化记录.md)。
