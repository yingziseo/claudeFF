# Windows 运行说明

V3 · Windows 11 x64。完整解压 ZIP，双击 `claudeFF.exe`。保留 `browser/`、`webview2/` 与程序的相对位置；内核已经随包，不需要下载。开发版产品登录可随意输入，Claude 官方登录自行完成。

1. 打开“全局连接”，点“粘贴识别”，或粘贴到快速导入框。支持 `地址:端口:用户名:密码` 和 HTTP/HTTPS/SOCKS5 URL。
2. 点“保存并检测”，查看真实出口、国家/城市、请求耗时。需要能访问代理网关的网络。
3. 点“打开 Claude.ai”。第一次开环境页和官网，以后恢复原来标签/对话。密码、Cookie、历史、书签保存在独立浏览器目录。
4. 需要 Code 时点“安装官方 Code”，下载校验官方二进制并由官方安装器安装到正常用户目录。无需 WSL、虚拟机、Node.js 或 npm；已有官方安装可直接复用。
5. “选择项目”指定本机工作目录，点“启动终端”，按官方提示登录。输入、Ctrl+C、缩放和重新启动按正常终端使用。

全局代理自动用于本应用启动的浏览器和 Code。运行时先关闭两端再修改代理；不改变系统代理。单独在其他终端运行 claude 不一定继承本应用代理，推荐从本应用启动。Code 不同步浏览器指纹或时区，不再使用旧隔离流程。

应用配置保存在 `%APPDATA%\claudeFF`。浏览器使用 `browser-profile`，升级程序 ZIP 不覆盖它。代理密码由 Windows DPAPI 保护，换 Windows 用户后需重新填写；清理缓存保留登录、密码与历史。

若“内置资源缺失”，重新完整解压，不能只复制 EXE。检测失败按界面区分认证、超时或协议错误；截图和反馈不要包含代理密码、Cookie、卡密或令牌。

上一版 v0.2.0-dev.1 不含内核且采用 WSL 方案，已被替代。当前构建/下载状态见 [验证报告](https://github.com/yingziseo/claudeFF/blob/main/docs/开发进度与验证报告.md)，不以旧 ZIP 作为新版交付。官方账号授权、实际模型请求、高 DPI、异常断电恢复等未实测项目如实记录。

当前交付为 v0.3.0-dev.1，完整 Windows ZIP 已发布。开发版未做发行签名，系统可能要求首次打开确认。官方 Code 登录若打开默认系统浏览器，它不会自动使用应用代理；可复制登录链接到受管浏览器打开。
