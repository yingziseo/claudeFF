# Windows 开发体验版运行说明

适用：Windows 11 x64。解压整个 ZIP，保留 `sandbox/` 与 `claudeFF.exe` 的相对位置，双击运行。管理界面需要 WebView2 Runtime。本版没有正式卡密，产品登录仍是开发交互；Claude 官网及 Code 的官方授权须自行完成。

## 首次体验

1. 在“全局连接”填写代理协议、网关主机、端口和认证，保存后检测。整个应用只使用这一份配置。密码由当前 Windows 用户的 DPAPI 保护。
2. 点击打开浏览器时自动准备固定版本指纹内核，也可以在浏览器页提前下载。下载通过全局代理，按官方发布资产 SHA-256 校验，不自行编译 Chromium。
3. 创建并打开浏览器。实际浏览器核验出口后，打开环境信息与 claude.ai 两个标签页。正常保存密码、登录、历史与书签，关窗后保留。
4. Code 页面点击安装。已有配置自动复用；无配置时先提示差异，再允许单独创建。需要 WSL2 和硬件虚拟化；未启用时使用界面启用按钮，完成 UAC/重启后重试。
5. 安装会下载已校验的 Ubuntu 系统到专用 `ClaudeFF` 发行版，安装隔离组件与官方 Code，不修改其他发行版。Code 使用非 root 用户、受限目录与禁止直连的网络规则。
6. 启动终端，按官方流程授权。浏览器 Cookie 不会复制给 Code；终端可能提供授权链接/粘贴代码，需用户完成。

## 项目与数据

- 首版使用项目副本：选择“导入项目副本”，复制所选目录到隔离系统 `/workspace/project-*`。不挂载整块 Windows 磁盘，不自动回写原目录。可在隔离终端通过 git clone/push 管理代码，或从 Windows 的 `\\wsl.localhost\ClaudeFF\workspace` 查看受管文件。
- 含符号链接或超 2GB 的项目需先整理独立副本，避免意外导入外部目录；失败不修改源目录。
- 应用数据在当前 Windows 用户应用配置目录的 `claudeFF`；浏览器 profile、数据库和 WSL 系统分开。替换程序 ZIP 不会清空数据。
- 修改全局代理/语言/时区前先停止两端。新配置须重新检测；已有代理密码留空可保留，取消保留选项可清除。
- 清理缓存只移除浏览器临时缓存，不删除密码、Cookie 或项目。不要手工删除 WSL 系统目录。

## 实机验收清单

- Windows 程序启动、明暗切换、高 DPI 和窗口缩放正常。
- 真实代理连接与错误凭据；浏览器核验出口，两个启动标签页、保存密码与重启登录保留。
- WSL2 缺失/重启/下载失败/重试；实际 Code 安装、官方授权、PTY 输入、Ctrl+C、窗口尺寸、退出与再次启动。
- Code 访问 `/mnt/c`、宿主 Windows 程序、任意本机目录及清空代理变量后直连均被拒绝。
- 浏览器与 Code 真实请求出口一致；断网、改代理、IPv6/DNS/UDP、异常关闭均无直连回退。
- 导入项目、修改文件、git 工作流可用且源目录不被悄悄覆盖。

全部依赖安装和构建在 GitHub Actions 完成。本开发版已有核心云测、真实 Windows 内核测试、Linux 隔离/官方 Code 安装及 GUI 进程启动存活证据；完整 Windows/WSL2 清单仍由用户实机验证。授权服务/面板已完成开发和云端联动测试，但生产未部署，开发 ZIP 不要求卡密。Claude 桌面客户端仍只预留入口。

## 反馈与恢复

体验问题请记录 Windows 版本、卡住的步骤、界面错误文案和复现操作；勿公开代理密码、Cookie、卡密或授权令牌。若程序初始化失败，先保留数据目录检查权限；跨 Windows 用户复制的 DPAPI 秘密需重新填写代理，不自动清空 profile。未来数据库版本会拒绝旧程序打开，不降级覆盖。

本 ZIP 不含完整 Chromium/Ubuntu，因此包体不代表安装后磁盘和内存占用。首次下载可能较大，Code 安装涉及系统确认和必要重启。开发版未做正式代码签名；正式售卖前另验收授权与发行。
