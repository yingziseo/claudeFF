# 技术栈与实现边界

版本：V2 · 2026-10-10。需求以 [开发项目计划](claudeFF开发项目计划.md) 为准；具体检查与未验证项见 [进度报告](开发进度与验证报告.md)。本文已由技术候选改为当前实现记录。

## 已采用技术

保留 Go + Wails 2 + React/TypeScript + SQLite。管理外壳使用系统 WebView2；真实浏览器是独立 Chromium 进程。用户要求 WSL2 强隔离，首次 Code 准备有系统、磁盘与内存开销，不能用小包体推导全部运行开销。

| 模块 | 当前方案 |
| --- | --- |
| 管理界面 | React 19.3、TypeScript 7.0、Vite 8.3、Tailwind 4.3、Radix、Lucide；固定 npm lock |
| Windows 外壳 | Wails 2.16.0；单实例、窗口生命周期、Go Invoke 绑定、内嵌前端 |
| 本地业务 | Go 1.26；唯一配置、代理及受管进程生命周期 |
| 数据 | database/sql + modernc SQLite 1.60.1；配置、历史检测、受保护授权会话 |
| 秘密 | Windows 用户级 DPAPI；跨用户/损坏秘密明确报错并允许重新填写 |
| 浏览器 | fingerprint-chromium 148.0.7778.215 Windows x64；独立 profile 与稳定种子 |
| 控制与观测 | chromedp 0.14.2；实际浏览器出口、UA、UA-CH、语言/时区、显示/硬件、Canvas 样本、音频采样率 |

Go 与 npm 的确切直接/间接依赖以仓库锁文件为准。不引入 Electron、Redis、Kubernetes、通用 Node 后端或微服务。

## 实际运行结构

```text
Windows Wails + React
  └─ Go / SQLite / DPAPI / 一份全局代理配置
      ├─ Windows 回环 relay → 指纹 Chromium（专用 profile）
      └─ wsl.exe 标准输入传配置 → 专用 ClaudeFF WSL2
          └─ root 回环 relay ← 仅允许此出口的 Code UID
              └─ bubblewrap → Code 全进程 + 子进程 + PTY

两个 relay 均只访问同一上游；浏览器与 Code 分别核验真实出口。
```

WSL 转发在隔离系统内，不依赖 Windows 回环穿透或监听 `0.0.0.0`。上游密码仅在 Windows DPAPI 和 root relay 运行内存使用；Code 环境变量只有本机受限转发入口。普通网页没有管理接口，浏览器环境页使用随机路径和 CSP，CDP 由受管进程控制。

## 内核与数据

锁定 [fingerprint-chromium](https://github.com/adryfish/fingerprint-chromium) 的 `148.0.7778.215` 预编译 ZIP，而未直接采用调研时最新且补丁源码延迟发布的版本。固定资产摘要、来源见 [来源文档](第三方许可与来源.md)。发布 tag 指向源码提交 `13b89eae304123f0710f2d33fd0816a2f61d7ffc`，已核对该提交包含 [指纹补丁目录](https://github.com/adryfish/fingerprint-chromium/tree/13b89eae304123f0710f2d33fd0816a2f61d7ffc/patches/extra/fingerprint)；固定二进制摘要与官方 release 元数据相符。这是来源对应记录，不宣称二进制已完成可复现编译审计。按需下载通过全局代理，摘要失败不启动；不在本机或云端重编 Chromium。

使用原生标签页/地址栏、一个稳定种子和一个持久 profile。真实 Windows 内核云测已验证认证测试代理、出口、双默认页、语言/时区观测，以及同种子重启 Canvas 样本和 localStorage 保留。密码保存、官网登录恢复、扩展和完整字体名单仍需用户实机检查，Google 专有同步不作为既有能力。

## 全局连接

依据 [Claude Code 网络配置](https://code.claude.com/docs/en/network-config)，Code 原生 HTTP/HTTPS 代理配置即可；SOCKS5 上游由 Go relay 适配，不修改 Code 或要求插件。

浏览器、全局检测和 Code 受限 UID 分别检测出口。同一网关不必然同一 IP；初次不一致禁止启动，运行中每分钟复核，失败或变化停止受管端。离线检测有有效期，历史值不冒充当前连接。运行时禁止修改共享配置，停止两端后修改令旧结果失效。

Code UID 的系统出站规则仅允许 root relay 的回环 TCP 端口，其余 IPv4/IPv6、UDP/DNS 直连都被拒绝；清除代理变量不能解除规则。浏览器使用代理、禁用 QUIC/非代理 UDP 和 WebRTC 相关策略；完整浏览器 DNS/IPv6/WebRTC 防泄漏仍待链路实测，不能用一个 HTTP 出口检查替代。

## 强隔离与项目

[官方 Bash sandbox](https://code.claude.com/docs/en/sandboxing) 的覆盖面不足以替代整进程边界。已采用 bubblewrap 约束整个 Code 及派生文件工具/MCP/hooks；并非仅打开 `sandbox.enabled`。Linux 云端已真实检查允许项目、拒绝宿主/root 路径、直接 IPv4/IPv6 和修改防火墙，且真实官方 Code 安装/版本启动通过。

专用 `ClaudeFF` 发行版不采用同名未受管系统，不修改其他发行版或用户 `.wslconfig`。`wsl.conf` 关闭 Windows 盘自动挂载、互操作、Windows PATH 与宿主时区继承；只重启本发行版。非特权 Code 进程仅看到系统只读依赖、自有 home、`/workspace` 和临时目录，没有 `/mnt`、`/run/WSL` 或上游秘密。

项目以独立副本导入，拒绝符号链接/特殊文件、限制 2GB，不自动回写 Windows 原目录。当前沙箱可访问自己的整个 `/workspace`，不能宣传为每个导入项目互相完全隔离。可在其中使用 git，或从 Windows 查看 `\\wsl.localhost\ClaudeFF\workspace`。

官方授权与安装分开，需要用户按终端完成授权链接/粘贴代码；不能复制浏览器 Cookie，也不能为 OAuth 全面放开宿主访问。完整 Windows WSL2 导入、登录回调、PTY 和项目流程由用户实机验收，Linux 检查不代替它们。

语言/时区沿用稳定档案，隔离系统时区及 Code 环境均应用。WSL Linux 与 Windows 浏览器平台客观不同，Canvas/WebGL 不当作 CLI 指纹复制。

## 授权与发行

后期授权代码已在核心首轮检查后加入，实际管理服务云测通过。当前卡密使用高熵随机值及服务端摘要，密码 scrypt，令牌摘要与 Windows DPAPI，正式模式后端强制授权并在不可用/撤销时取消进行中操作和受管端；开发模式保留无联网产品登录。

当前发行是开发体验 ZIP，内核/rootfs 在用户机器按需下载，官方 Code stable 安装版本记录在状态中。授权服务独立打包但未部署生产 HTTPS，策略、运维、品牌及完整发行通知需商业发布前收敛。详见 [授权说明](授权服务运行说明.md)。

全部依赖安装、编译、类型检查、测试、浏览器截图与打包只在 GitHub Actions。云端证据与用户实机清单分别记录。
