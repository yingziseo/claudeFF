2026-10-11 · V3，以最新简化需求为准。

保留 Go + Wails 2 + React/TypeScript + SQLite。Windows 管理界面使用随包固定 WebView2，macOS 使用系统 WKWebView；真实浏览器是完整 fingerprint-chromium 独立进程。Code 直接运行官方原生二进制，取消虚拟化和额外隔离系统。

| 模块 | 方案 |
| --- | --- |
| 指纹浏览器 | fingerprint-chromium 148.0.7778.215 成品，稳定种子、持久 profile、原生会话 + 私有 URL 检查点 |
| 全局代理 | Go CONNECT + HTTP/HTTPS/SOCKS5 上游，一份设置、一个本机回环入口 |
| Code | 官方最新安装器二进制和官方 SHA-256 清单，调用 install stable；Windows ConPTY / macOS PTY |
| 项目 | 用户选择本机目录，直接使用，不复制、不虚拟挂载 |
| 秘密 | Windows DPAPI，macOS Keychain 保存加密密钥，AES-GCM 保护数据库秘密 |
| 后期授权 | 单 Go 服务 + SQLite，开发包保留跳过；生产未部署 |
| 构建 | GitHub Actions 对应平台运行器，禁止在当前服务器安装/编译/测试 |

浏览器锁定源码提交 `13b89eae304123f0710f2d33fd0816a2f61d7ffc`，指纹补丁来源为 [上游目录](https://github.com/adryfish/fingerprint-chromium/tree/13b89eae304123f0710f2d33fd0816a2f61d7ffc/patches/extra/fingerprint)。成品按官方摘要校验，保留原生文件和第三方通知，不重编 Chromium、不宣称完全可复现审计或等同完整 Google Chrome。

启动检测使用独立临时标签；恢复既有会话而不导航覆盖对话。首次提供环境页和官网，以后继续原来的 URL、登录和浏览数据。静态 URL 检查点保存在用户配置目录，不进仓库或诊断包。

Code 设置基于 [官方代理文档](https://code.claude.com/docs/en/network-config)，官方安装基于 [官方安装器](https://claude.ai/install.ps1) 和 [平台说明](https://code.claude.com/docs/en/setup)。清理冲突代理变量，不修改本机系统代理、不覆盖用户 settings.json、不改官方源码。SOCKS5 通过应用 HTTP 隧道适配。启动前单独验证传给 Code 的回环代理出口；这不是其所有子进程强制出站限制。

原生 Code 可读取获准的本机信息、知道自身代理配置；服务端正常 HTTPS 连接看到代理出口，也可能识别其代理属性。取消沙箱后不承诺真实公网 IP 无法通过其他直连获取、不伪装 Code 指纹、不复制浏览器时区。后期若用户明确恢复强隔离，再另作需求变更，不能自行保留旧复杂方案。

完整 ZIP 比旧版大，是因为浏览器与 Windows WebView2 直接内置。只有官方 Code 本体在线安装；不包含 WSL、虚拟机或 Linux 镜像。macOS 内核架构必须在云端检查，不用 Intel 二进制冒充 Apple Silicon 原生支持。具体测试状态见验证报告。

当前上游 macOS 148 DMG 已在云端确认仅含 arm64 内核。Apple Silicon 提供浏览器 + Code；Intel Mac 当前提供原生 Code，浏览器入口明确不可用，不用普通 Chromium 冒充指纹内核，也不分发错误架构的程序。
