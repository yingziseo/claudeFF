## 用户实机与商业发布待办

用户明确接受以后在 Windows 安装体验。按 [运行说明](Windows运行说明.md) 测 WSL2 启用/导入/重启、实际住宅代理、Claude 官方授权、终端/项目和持久登录；补 DNS/IPv6/WebRTC、权限/字体、高 DPI、断网/异常退出/恢复、磁盘及内存开销。工具不推断住宅属性，不伪造浏览器与 Linux 完整设备信息相同。

后期卡密代码已完成且测试通过，但开发 ZIP 仍保留跳过登录。生产 HTTPS 域名、管理凭据、授权规则确认、限流/备份运维和关闭开发入口的正式包需商业发布前完成，不能把本轮开发包当成已验收的售卖版本。

所有依赖安装、类型检查、编译、测试、安装脚本运行和截图均在 GitHub Actions；本机只编辑、轻量检查、Git 与下载/静态检查云产物，没有运行项目构建或安装 Code。
