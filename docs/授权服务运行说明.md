# 授权服务与管理面板：开发验证版

V2 核心云测之后（当前 V3 改为原生 Code，需重新验收），已实现后期授权模块。服务部署、正式策略确认与 Windows 授权实机验收尚未完成；默认 Windows ZIP 仍为开发体验版，不可直接作为售卖版本。

## 部署材料

GitHub Actions 的 `license-service` 产物包含 Linux x64 单程序、React 面板与说明。解压到独立目录，以受限服务用户运行：

```bash
# 管理员令牌由操作者生成并通过受保护环境配置，至少 32 字符。
export CLAUDEFF_ADMIN_TOKEN='替换为自己的随机管理令牌'
./license-server -listen 127.0.0.1:8787 -db /绝对路径/license.db -web frontend/dist
```

不要将生产令牌提交仓库、放在 URL 或公开终端日志里。对外访问需 HTTPS 反向代理；服务默认仅监听回环，不自动开放端口。面板路径 `/claudeFF/#admin`，API 与面板同源，不需要开放任意 CORS。

公开 GitHub Pages 的 `#admin` 是明确标记的示例预览；服务产物使用真实 API，不接受随意输入进入。管理员令牌只在当前页面内存使用，卡密明文只在生成时显示，服务保存其高熵摘要。

## 当前实现与待确认策略

- 卡密永久有效，激活绑定一个产品账号；重复注册激活被原子阻止，同一账号正常登录不视为新激活。
- 不实施硬件设备绑定；当前不限制同账号会话数量。账号恢复/换机/共享使用规则需商业发布前明确。
- 密码随机盐 scrypt；会话随机令牌仅保存摘要，客户端会话经 DPAPI 保护。当前会话 14 天有效，到期重新登录，不是卡密到期。
- 正式客户端每分钟心跳；在线显示根据最近 3 分钟心跳推算。只上报版本与浏览器/Code 运行布尔值，不上报代码、对话、Cookie 或代理信息。
- 当前草案没有离线宽限，授权不可用时停止受管浏览器和 Code。频率与宽限是可评审默认值，正式售卖前须确定，并按真实使用测试调整。
- 撤销后原会话和重新登录都被拒绝。生成/撤销记录在服务数据库 audit 表，最小管理权限是单一管理员。
- 正式编译通过 `releaseMode=production` 与 `licenseURL=https://授权域名` 配置。服务地址缺失时拒绝正式授权，不退回开发登录。默认构建仍为 development。

例如在已配置服务后，由 Windows 云端工作流调用：

```text
wails build -platform windows/amd64 -skipbindings -s -ldflags "-X main.releaseMode=production -X main.licenseURL=https://授权域名"
```

域名、TLS 和生产管理令牌须由部署操作者提供；本轮没有部署外部服务或生成生产秘密。

## 验证范围

云测包含卡密生成、真实注册激活、重复激活拒绝、心跳、在线过期、撤销与撤销后登录拒绝；管理面板另执行真实 Go 服务的浏览器交互测试。密码、卡密及令牌不出现在列表 API。

尚需正式策略确认、HTTPS 部署、限流与备份运维演练，以及 Windows 正式客户端登录/记住登录/撤销中止/离线行为验收。授权不承诺无法破解；当前开发 ZIP 的跳过入口有意保留。
