# 需求沟通与修订记录

2026-10-12 · V4 基座选型修订；V3 为已有实现，旧 V2 强隔离与按需内核下载已被替代。

最新要求：复用持续维护的完整产品代码，评估是否有比 Donut 更合适的基座。目前源码评估 Donut 首选、CloakBrowser Manager 备选，不等于完成迁移或实测最优。测试项目以可用性优先，不因假设商业发行阻止测试。代理通过免费 IP 接口验证，地区与连通性分开；实际秒退出需解决。已直接访问腾讯文档、查看比特截图，启动页加入 ToDetect/BrowserLeaks。依据见 [基座评估](指纹浏览器基座选型评估.md)。

| 用户最新要求 | 当前落实规则 |
| --- | --- |
| 关联仓库并有 push 权限 | yingziseo/claudeFF，重大变更更新工作日志后正常推送 |
| 云构建，服务器配置差 | 依赖、构建、编译测试、前端测试都在 GitHub Actions |
| 单账号工具 | 一个浏览器环境、一个应用全局代理，浏览器/Code 两个核心入口，桌面版开发中 |
| 正常指纹浏览器体验 | 复用开源成品完整内核，保留原生 UI/密码/历史/书签；重启恢复上次标签和具体对话 |
| 基础资源全部内置 | Windows ZIP 含 Chromium 和固定 WebView2，仅 Code 在线安装 |
| 真实代理可用 | 导入格式校验、认证/超时错误、代理内备用检测站；真实 Windows 客户端链路验证 |
| 一键粘贴 | 四段式、URL、用户名密码格式自动填充，密码遮蔽 |
| IPDeep 推荐 | 本地原图、指定推荐链接、多地区/最低 $2/IP 用户给定文案、固定大陆网络红字 |
| Code 支持 Windows/苹果 | 官方原生安装，自动共享代理；按平台分别测试和发布 |
| 最终选择简单方案 | 取消 WSL2/虚拟机/沙箱/出站防火墙、Code 指纹同步、先浏览器门槛和项目副本 |
| 界面降噪、克制 | 去掉装饰预览、重复解释和安装细节堆积；保留真实状态和必要操作 |
| 图标 | Claude 官方标识，普通操作 Lucide；不使用旧生图 logo |
| 前期登录 | 任意输入即跳过的开发 UI；与官方 Claude 登录分开 |
| 授权最后 | 永久联网卡密与“卡密和用户管理面板”；不加套餐/支付/设备绑定 |
| 无需等待前端确认 | 自主完成核心和界面优化，最后提供 ZIP、链接、真实报告 |

关于技术边界：Code 不具备网页 Canvas/WebGL 那类指纹，不意味着无法读取本机时区；原生程序可知道代理设置，正常隧道请求显示代理出口，但没有强制出站限制时不能保证不存在直连。强隔离也不等于“完美隐藏”。用户了解上述区别后明确选择简单方案，不再以此前的强隔离要求阻挡开发。
