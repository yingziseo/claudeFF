## 必须准确表达的边界

- 一致性来自同一份稳定配置及实际观测，不来自机械复制全部浏览器指纹。
- Code 与浏览器有不同协议栈和运行平台；不伪造它们完全相同。明确显示适用同步项、浏览器专属项、仍存在的平台差异。
- WSL2 与官方 Bash sandbox 都不是“已实现整进程隔离”的证据，需要权限、网络、宿主访问及子进程测试。
- 官网是否已登录不作为创建 Code 的硬门槛，也不等同于 Code 已授权；产品卡密身份与两者分开。
- 公开网页已更新为 V2 单账号示例预览；实际业务以 Windows 程序及对应云测为依据。

## 保留但后续收敛的事项

内核 148 与 Ubuntu rootfs 已固定摘要、按需下载；专用 WSL2 + bubblewrap + UID 防火墙已实现，项目采用独立副本。Windows 实际授权/PTY/资源开销、完整防泄漏和恢复场景尚需用户实机测试。授权已实现草案：永久卡密绑定产品账号、无设备绑定、14 天会话、每分钟心跳、最近 3 分钟在线、目前无离线宽限。草案未替代用户对商业规则的确认；生产 HTTPS、凭据及换机/恢复/运维策略后续收敛。
