## 需要补齐的核心边界

- **IP 独占的有效范围**：使用实际出口 IP 而非代理地址作为占用依据；统一 IPv4/IPv6 表示，原子处理并发启动。固定出口代理优先，轮换代理的运行期策略仍待确定。
- **启动流程**：代理检测、IP 预占、进程启动、实际 Chromium 网络复核、进入可用状态；任一步失败都关闭已创建资源并释放占用。
- **故障与恢复**：代理断线不得直连；管理程序多开、浏览器被手工关闭、异常退出和残留进程都需要真实状态恢复。不能重启客户端就把仍运行的 IP 标成空闲。
- **环境生命周期**：区分检测中、启动中、运行中、关闭中、已关闭和失败；禁止重复点击并发启动，运行期间修改关键配置前必须关闭环境。
- **数据保护**：每个环境独立目录；删除环境明确提示是否移除浏览数据，清缓存不得连同 Cookie、账号或配置一起误删。
- **指纹兼容**：使用真实内核版本对应的参数，不伪造 User-Agent 版本；支持与不支持的能力分开展示。已有环境参数保持稳定。
- **网络检测故障**：区分代理失败和检测服务失败；IP、地区和住宅属性分开报告，地区未知不得伪造成检测成功的具体地点。
- **本地数据安全**：密码哈希、代理秘密加密、记住登录令牌保护、日志脱敏；数据默认存放 Windows 标准应用数据目录。
- **本地接口安全**：代理桥接、环境首页和 CDP 仅绑定回环地址；不对局域网暴露管理端口，不让网页获得任意环境控制权限。
- **Windows 兼容**：检查 WebView2 和 Chromium；覆盖中文及含空格路径、DPI 缩放、程序异常关闭和更新后保留数据。
- **验收可信性**：云端编译、模拟代理测试、真实代理出口测试及 Windows 实机启动分别记录，不能互相替代。

## 商业授权与后台的后期边界

- “永久有效”指授权没有套餐到期日，不等于无需核实撤销状态。复核频率和离线宽限需要在授权阶段前明确。
- 在线状态由客户端心跳和最后活动时间推算，后台必须显示最近上报时间，不能把它当作实时绝对准确的状态。
- 使用概况建议仅包含客户端版本、环境总数和运行数量；不默认上传网页内容、Cookie、浏览历史或代理密码。
- 卡密签发私钥及后台管理凭据不进入客户端、公开仓库或构建日志；客户端只能得到必要的验证材料。
- 联网激活便于控制正常客户端的激活与撤销，但本地功能仍可能被修改后的客户端绕过，不承诺绝对防破解。
- 卡密绑定一个用户还是限制激活实例、是否允许换电脑、如何恢复账号，以及管理员的操作权限，在后期授权设计时明确。当前没有新增设备绑定的决定。
- 不增加支付、订单、会员等级、续费、云端浏览器数据同步或大型商业运营后台。
