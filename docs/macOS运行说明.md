# macOS 运行说明

V3 · 官方 Claude Code 原生支持 Intel/Apple Silicon，最低系统版本遵循官方要求（当前 macOS 13+）。本应用 macOS 产物与内置浏览器兼容架构须以发布验证报告为准，不用 Windows 测试冒充。

完整解压，将 claudeFF.app 放到本机目录运行；管理界面使用系统 WKWebView。与 Windows 共用相同界面与全局代理流程：粘贴代理 → 保存检测 → 打开浏览器，或安装官方 Code → 选择本机项目 → 启动终端。

Code 使用官方 darwin-x64/darwin-arm64 对应二进制、官方 SHA-256 校验及 install stable，PTY 提供本机终端。没有 Linux 虚拟机、容器或隔离沙箱，也不复制项目。代理只作用于从本应用启动的进程，不改系统网络设置。

代理秘密由 macOS Keychain 保护。首次钥匙串访问可能出现系统确认；程序更新后的身份变化按系统提示处理。浏览器数据和数据库在用户配置目录，替换 app 不删除登录与对话。用户自行完成 Claude 官方授权。

开发包尚未完成开发者账号签名/公证，不等于正式商业发布。系统可能要求用户确认首次打开；不自动移除整个磁盘或其他程序的安全属性。具体架构、真实启动测试和剩余验收见验证报告。

当前上游 macOS 148 DMG 已在云端确认仅含 arm64 内核。Apple Silicon 提供浏览器 + Code；Intel Mac 当前提供原生 Code，浏览器入口明确不可用，不用普通 Chromium 冒充指纹内核，也不分发错误架构的程序。
