# Windows 使用说明

这是 claudeFF 0.1.2 原型。请完整解压 ZIP，然后打开 `ClaudePrivacy.exe`；不要直接在压缩包中运行。其余程序是自动调用的后台组件。

## 双击没有反应时

本包是 Windows **x64** 自包含版本。先完整解压到新的普通目录，不要只复制 EXE，也不要覆盖旧目录。直接双击 `ClaudePrivacy.exe`。`PrivacyAudit.exe` 和 `LocalProxy.exe` 是内部组件，不会显示主窗口。

仍打不开时运行 `Diagnose.cmd`。它只检查包内文件哈希、系统版本和启动状态，不修改防护策略。结束后打开诊断目录；提供其中的 `diagnosis.txt` 与 `startup.log`（如果存在）即可继续定位。日志包含本地路径，可先检查后分享。

新版会把托管启动异常写入 `%LOCALAPPDATA%\ClaudeFF\Logs\startup.log` 并弹出错误提示；运行时尚未加载就失败的情况由诊断脚本收集退出码与宿主日志。**尚未取得用户 Windows 10 目标机日志，因此本版不宣称该故障已修复。**

## 先准备环境

安装官方 x64 Sandboxie Plus：https://sandboxie-plus.com/downloads/ 。本工具不附带第三方驱动，不自动安装或修改其他代理程序。不同 Sandboxie 版本/许可证的功能可用性可能不同，应用配置本身不能证明功能可用。

在“隐私防护 → 安装与启动设置”选择安装目录（默认 `C:\Program Files\Sandboxie-Plus`）。可以暂不安装 Claude，先验证访问限制；使用测试时再选择实际 Claude `.exe`。特殊打包入口或 MSIX 启动方式可能不兼容，不能把未启动成功当成已受保护。

## 开启和验证

1. 选择浏览器资料保护，或添加要限制的私人目录。只会覆盖列出的路径；便携版/自定义浏览器目录需手动添加。
2. 点击“开启防护”。这是应用配置，还没有验证。
3. 点击“验证防护”。工具自动运行宿主和沙箱探针，检查实际允许/拒绝结果。
4. 通过表示本次列出的、已开启的防护项通过；没有列出的功能不在承诺范围内。
5. 导出本次报告可供排查。报告会将用户目录替换为 `%USERPROFILE%`，但其他自定义路径和测试出口 IP 仍可能包含个人信息。

文件不存在、超时或宿主基线本来不可读会标记未验证，不会显示通过。注册表测试覆盖工具自建测试键及已发现并限制的浏览器偏好键，不表示所有浏览器/系统注册表均受限。

## 网络

默认复用自己的全局代理；“检测出口 IP”只检查这一请求。

需要实验性的 TCP 接管时，填写 SOCKS5 地址、端口和认证信息，先“保存并测试代理”，勾选“使用住宅 SOCKS5 代理”，再开启防护。密码使用当前用户 Windows DPAPI 保存；不会把住宅代理密码放进 Sandboxie.ini。

此模式需要 Sandboxie 支持对应代理功能。验证会用随机挑战检查沙箱 TCP 连接确实到达本地代理，再检查公网出口。仅 TCP：没有 UDP/DNS 接管、全局代理或零泄漏保证。不要把它当成全功能 VPN。代理不可用时，本桥接不会主动直连回退，但它不能覆盖 Sandboxie 未接管的路径。

主窗口关闭后代理后台进程继续运行；本版不注册开机服务。重启系统后先恢复配置并重新开启防护，不要直接沿用上次验证结论。恢复访问限制同时停止本工具的代理。

## 可选数据使用

在 Claude 中打开 Settings → Privacy，并保持模型改进开关可见。点击工具中的“关闭模型改进”。工具仅操作能通过辅助功能接口识别的官方模型改进开关；识别失败时不猜测点击，不创建假配置键。

关闭后读回确认的项目才加入验证清单。后续验证同样需要该设置页面可见。模型改进偏好可能同步到其他设备；它不等于“全部遥测关闭”。客户端崩溃上报、位置偏好等未自动操作，不列入防护验证。

## 运行 Claude

选择 Claude 实际程序位置，先退出已在沙箱外运行的实例，再点“启动 Claude”。工具尝试确认进程进入目标沙箱。普通快捷方式未做强制入箱，不能算受保护入口。

请你实际测试：登录和浏览器回调、发消息与流式回复、历史记录、附件上传下载、所需连接器/本地工具、关闭后重开和更新。这些属于客户端功能验收，不计入防护检测分数。

被限制的私人目录不能直接作为附件来源。可把要上传的文件复制到未受限的交换目录；下载到沙箱内的文件也需通过 Sandboxie 恢复。本工具不会删除这些数据。

## 恢复与问题处理

- “关闭窗口”保留沙箱规则和代理后台进程。
- “恢复本工具的访问限制”要求先退出专属沙箱内的程序，不会强制关闭你的工作；保留沙箱数据。
- 模型改进偏好在对应页面单独恢复，恢复会重新开启本工具曾关闭的选项。
- 写入权限失败：检查 Sandboxie 配置锁；必要时在同一 Windows 用户下以管理员身份重试。不要用另一账户提升后混用两份配置。
- 配置被外部修改：工具停止自动覆盖；在 Sandboxie 中检查名称以 `ClaudeFF_` 开头的专属沙箱。
- 配置未完成：恢复后再试。不要删除恢复记录来强行覆盖同名沙箱。
- 探针失败：确认完整解压到未受限的本地目录，所有程序齐全，Sandboxie 驱动和服务正常。

本地设置、恢复记录与最近报告位于 `%LOCALAPPDATA%\ClaudeFF`。尚无自动更新、后台上传或账户服务。
