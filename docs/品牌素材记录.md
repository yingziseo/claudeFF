# 品牌素材记录

版本：V2 · 2026-10-10。用户最新要求：项目与 Claude 产品入口使用 Claude 官方图标；常规功能图标采用主流库。此要求替代此前 imagegen 原创 logo 要求。

## 当前采用方向

| 用途 | 素材 |
| --- | --- |
| claudeFF 项目标识、Claude.ai、Code、桌面版入口 | Claude 官方图标；产品文字区分入口，不自造不同品牌标识 |
| 设置、复制、返回、文件夹、进度等功能 | 已有 lucide-react，保持同一套尺寸与笔画 |
| favicon | 下一版替换为官方素材 |

已获取的官方参考素材来源：[Claude 官方网站](https://claude.com/) 页面声明的 [favicon 原文件](https://assets.claude.com/95a868946ac8a31e5ff832e2899f294aa368b836.png)。该文件为 32×32 PNG，适合小尺寸；大尺寸位置应获取官方矢量或高分辨率素材，不放大后冒充高质量图标。当前前端尚未替换素材，本轮仅统一文档。

品牌素材归相应权利人；使用官方素材不表示工具由 Anthropic 出品或获得授权。保留第三方工具身份，商业发布前核对品牌使用条件，不能因为可下载就标成自由商用。常规库图标随依赖保留许可证。
