# 品牌素材记录

## claudeFF 图标

- 用户要求：使用生图技能生成符合统一设计风格的 logo、图标等素材。
- 生成方式：imagegen 技能的内置 image_gen 工具，未使用 CLI 或另外的 API Key。
- 项目文件：`frontend/public/brand/claudeff-icon.png`。
- 使用位置：登录页面、侧栏、设置关于区域、网页 favicon。
- 视觉方向：蓝色圆角应用图标，两个错位的独立浏览器窗口，简洁轮廓，适配简约桌面工具界面。
- 普通操作图标使用 Lucide，统一笔画和尺寸；不为每个按钮引入不同风格的位图。
