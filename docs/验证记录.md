# 本次开发验证记录

环境：Linux x64，.NET SDK 10.0.401；目标 Windows x64。此记录不代表已在 Windows 运行过本工具。

已执行：

- 整个解决方案 Release 编译，零警告、零错误。
- 21 项公共逻辑测试：空清单、失败/未知状态、基线不足、资源缺失、规则路径注入、代理参数、报告序列化、恢复时外部冲突与中断状态。
- 3 项真实本地 TCP 集成测试：SOCKS 握手/随机挑战回显，上游不可达返回失败，上游用户名密码认证/双向转发/半关闭。
- Windows x64 自包含发布：主程序、内部探针和内部 TCP 代理；检查 Windows PE 文件头与 ZIP 完整性，生成 SHA-256 校验清单。
- 1280px 与 375px 网页布局预览截图。仅为布局检查，不是 WPF 原生截图，也不代表 Windows 功能测试。

待用户目标机执行：Sandboxie 驱动/API、实际沙箱访问拒绝、TCP 重定向许可与版本支持、隐私开关辅助功能接口、原生界面、高 DPI、Claude 登录和日常使用。
